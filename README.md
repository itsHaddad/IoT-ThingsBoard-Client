# IoT-ThingsBoard-Client

This code is used to run an emulation of a temperature sensor device with MQTT and the ThingsBaord.

## Development

### README Link Checker

Use the link checker script to verify Markdown URLs before publishing:

```bash
python tools/check_readme_links.py --timeout 5
```

Pass `--file` to target a different Markdown file and `--ignore` with comma-separated hostnames to skip domains that should not be validated.
